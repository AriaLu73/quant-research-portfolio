## About

I explore how observations depend on their past and how those relationships can inform forecasts. This portfolio brings together my time series analyses, from autocorrelation to predictive modeling.

Each project has its own question, analysis, and conclusions. Applications may differ across projects; the shared focus is careful reasoning about time-dependent data.

## Organization

Each work lives in a separate directory under `projects/`. Its README introduces the study, while supporting notebooks, scripts, and figures sit alongside it as needed.

I add new projects using numbered, descriptive directory names and link them in the index above. Large datasets remain outside Git; each project documents its own data source.

## Research Approach

1. **Ask a question** — identify the pattern or forecasting problem.
2. **Form a hypothesis** — make the assumptions and expected relationships explicit.
3. **Design the experiment** — define the data, comparisons, and evaluation procedure.
4. **Test the hypothesis** — examine evidence and uncertainty.
5. **Draw conclusions** — report findings, limitations, and negative results.
