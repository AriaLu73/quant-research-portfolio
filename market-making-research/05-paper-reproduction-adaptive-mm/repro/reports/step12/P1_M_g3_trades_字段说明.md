# P1_M_g3(原论文目录)成交明细:字段说明与按日汇总(用户 2026-11-08 要求)

文件:`P1_M_g3_250ms_trades_XBTUSDTM.csv`、`P1_M_g3_1000ms_trades_XBTUSDCM.csv`。来源 Table 8 l3sim 列(data/step14),样本日 10-16 / 17 / 18,l3sim 精确排队、post-only、延迟 1.8 ms,目录 = Part A g3 目录(队首口径估的需求,按用户 11-07 裁决待重估)。
P1 没有市价单、没有段、没有日内平仓;库存整天延续,**每天最后一行 `day_end_mark_to_market` 是把当日残余库存按当日最后中价计价的虚拟行**(Table 8 口径:W + I × 日末中价),不是真实成交;次日库存从 0 开始(每天独立回放)。
一笔吃单扫过我方价位时,引擎按 L3 逐笔成交分配,所以同一时刻可能有多行(同 ts、同 decision_ts)。

| 列 | 含义 | 单位 |
|---|---|---|
| ts_utc / ts_ns | 成交时刻(交易所时间) | UTC / ns |
| day | 回放日 | |
| event | maker_fill = 挂单被吃单成交;day_end_mark_to_market = 日末残余按中价计价(虚拟) | |
| side | 我方方向:sell = 我方卖单被买吃单打到;buy = 我方买单被卖吃单打到 | |
| price_* | 成交价(= 我方挂单价) | USDT / USDC |
| qty_contracts | 张数(XBTUSDTM 1 张 = 0.001 BTC;XBTUSDCM 1 张 = 0.0001 BTC) | 张 |
| notional_* | 成交额 = 价 × 张 × 每张币数 | USDT / USDC |
| cash_flow_* | 现金变动:卖 +、买 − | USDT / USDC |
| rebate_* | 返佣 = 张数 × 返佣率(USDT 我方费率 / USDC 我方费率)× 当日日末中价 × 每张币数(Table 8 口径) | USDT / USDC |
| inventory_after_contracts | 本行之后的库存(多 +、空 −) | 张 |
| cum_pnl_excl_rebate_* | 累计 现金 + 日末计价,不含返佣 | USDT / USDC |
| cum_pnl_incl_rebate_* | 同上 + 返佣 | USDT / USDC |
| decision_ts_utc | 这张单下单的决策时刻(Δt 边界后第一条行情) | UTC |
| mid_at_decision_* | 下单时刻中价 | USDT / USDC |
| quote_distance_ticks | 报价距离 = 下单时刻 |挂单价 − 中价|(目录给的 L⁺ / L⁻ 取整后) | tick(0.1) |
| mid_before_fill_* | 成交前最后一个 BBO 的中价(l3sim 里挂单只在真实吃单扫到时成交,盘口穿过我方价位后单子仍挂着,这个值可能已越过挂单价) | USDT / USDC |
| markout_5s_ticks | 成交后 5 s 中价相对成交价的有利方向变动(卖:成交价 − 5 s 后中价;买:反之);无 5 s 内 BBO 为空 | tick |
| ahead0_contracts | 进簿时同价位排在我方前面的张数(0 = 队首) | 张 |
| ahead_at_fill_contracts | 成交时前方张数 | 张 |
| queue_wait_ms | 进簿到成交的等待 | ms |
| sweep_qty_contracts | 打到我方的那笔吃单总张数 | 张 |
| level0_ticks | 进簿时挂单价离同侧最优价的 tick 数(0 = 贴盘口) | tick |
