# 公式核对:基准模型(AS 与 GLFT)对照原文

核对日期:2026-10-07。文献编号见同目录《文献台账.md》。

- AS 对照的是期刊版(L01,Quantitative Finance 8(3) 217–224),式号与页码为期刊版。
- GLFT 对照的是 **arXiv:1105.3115v5**(L02)。该预印本的公式没有编号,只能给页码;期刊版(Mathematics and Financial Economics 7(4))未取得,编号未核对。
- 带下单量 Δ 的版本对照的是 **arXiv:1605.01862v5**(L03),式号为预印本式号;期刊版未取得。

## 1. 结论

任务书给的五个式子,与原文逐项比对后**代数形式全部一致,符号方向一致**,任务书的 κ 就是原文的 k。没有发现抄错的项。

但任务书漏写了使这些式子成立的条件,共 9 处,按对实现的影响排序:

| # | 问题 | 涉及 | 原文依据 |
|---|---|---|---|
| D1 | AS 两式是近似,不是精确解:对库存 q 做渐近展开,并对成交到达项取一阶线性近似 | AS | L01 §3.2,式(22)、(26),p.221 |
| D2 | AS 近似只在 t 接近 T 时成立;远离 T 时最优报价几乎不随 t 变 | AS | L02 p.8 正文与脚注 8 |
| D3 | GLFT 两式是两步近似:先取 T→∞ 极限(精确),再用连续高斯函数代替离散特征向量(原文称 heuristic);库存大时不准 | GLFT | L02 定理 2 p.10;命题 3 及其后 p.11–12 |
| D4 | GLFT 模型里有库存上限 Q,闭式近似里 Q 消失了;到达 ±Q 时原模型单边不报价,闭式不体现 | GLFT | L02 §2 p.5;定理 1 的条件 q ≠ Q、q ≠ −Q,p.7 |
| D5 | q 的含义:两篇里都是"以单笔下单量为单位的整数",不是币数、不是美元名义额 | AS、GLFT | L01 §2.4 p.219;L02 §2 p.4 及脚注 5 |
| D6 | γ/κ 只有在"一笔 = 1 个单位"时才无量纲;单笔为 Δ 个单位时要写成 γΔ/κ | AS、GLFT | L03 式(4.6)(4.7) p.21 |
| D7 | δ、r、P 都以**参考价 S** 为基准;AS 称它为中间价,GLFT 说可以是平滑后的中间价。任务书没说 S 取什么 | AS、GLFT | L01 §2.1、§2.4;L02 p.4 脚注 3 |
| D8 | AS 的点差式(30) 里没有 A;GLFT 的式子里有 A。两个模型对"成交越频繁报价怎么变"的回答不同,不能把同一组参数在两式间互换后比较 | AS、GLFT | L01 式(30);L02 p.11 |
| D9 | 两篇都没有手续费/返佣、tick、排队、延迟、逆向选择;任务书的式子直接用于本市场时这些全部缺失 | AS、GLFT | L01 §2;L02 §2、§7 |

下面逐式给出比对。

## 2. AS 逐项比对

### 2.1 保留价

| | 式子 |
|---|---|
| 任务书 | `r_t = S_t − q_t·γ·σ²·(T − t)` |
| 原文 式(8) p.219、式(29) p.221 | `r(s, q, t) = s − qγσ²(T − t)` |

逐项:

- `S_t` ↔ `s`:原文是 t 时刻的中间价(式(1):`dS_u = σ dW_u`,"with initial value S_t = s")。一致。
- `q_t` ↔ `q`:原文 "given that the agent is holding q stocks"。数量单位是股,每次成交一股(§2.4:"committed to respectively buy and sell one share of stock")。任务书没写单位(D5)。
- 符号:q > 0 时 r < s。原文 p.219:"If the agent is long stock (q > 0), the reservation price is below the mid-price"。一致。
- 精确还是近似:式(8) 在"不允许交易、冻结库存"的设定下是精确的(由式(3)–(7) 推出,r 定义为 r^a 与 r^b 的平均)。式(29) 是允许挂单时的结果,它是近似:原文 p.221 "for this linear approximation of the order arrival term, we obtain the same indifference price"。任务书把它当作模型的结论直接写出,没有标明近似(D1)。

### 2.2 点差

| | 式子 |
|---|---|
| 任务书 | `δ^a + δ^b = γ·σ²·(T − t) + (2/γ)·ln(1 + γ/κ)` |
| 原文 式(30) p.221 | `δ^a + δ^b = γσ²(T − t) + (2/γ) ln(1 + γ/k)` |

逐项:

- κ ↔ k:原文强度为 `λ^a(δ) = λ^b(δ) = A e^{−kδ}`(式(20) p.221)。任务书的 κ 即 k。一致。
- `δ^b = s − p^b`,`δ^a = p^a − s`(§2.4 p.219):都是到中间价的距离,正值表示在中间价外侧。
- 来源:式(25) `δ^a + δ^b = −2θ²(s, t) + (2/γ) ln(1 + γ/k)` 代入 `θ² = −(1/2)σ²γ(T − t)`(式(28) 的解)。式(25) 本身来自 θ 对 q 的展开式(22) 截断;式(28) 来自到达项的一阶近似式(26)。所以式(30) 有两层近似(D1)。原文 p.221 还说明:"if we had taken a quadratic approximation of the order arrival term, we would still obtain θ¹ = s, but the sensitivity term θ²(s, t) would solve a nonlinear PDE."
- 点差与库存无关:原文 p.221 "The bid–ask spread in (25) is independent of the inventory. This follows from our assumption of exponential arrival rates." 一致。
- A 不出现在式(30) 中(D8)。
- 适用区间:L02 脚注 8(p.8)把 AS 近似改写为 `δ^{b*}_t ≃ (1/γ) ln(1 + γ/k) + ((1 + 2q)/2) γσ²(T − t)`,`δ^{a*}_t ≃ (1/γ) ln(1 + γ/k) + ((1 − 2q)/2) γσ²(T − t)`,并说 "these approximations are nothing but the Taylor expansions of the optimal quotes for t close to T";正文 p.8 说最优报价 "almost independent of t, as soon as t is far from the terminal time T. This observation is at odds with the approximations proposed in Avellaneda and Stoikov"(D2)。

### 2.3 买卖报价

| | 式子 |
|---|---|
| 任务书 | `P_b = r − (δ^a + δ^b)/2`,`P_a = r + (δ^a + δ^b)/2` |
| 原文 | 没有写出 P_b、P_a 的显式式子。p.221:"We then set a bid/ask spread given by (30) around this indifference or reservation price." |

- 任务书的写法是对这句话的直接展开,与原文一致。
- 交叉验证:由任务书得 `s − P_b = qγσ²(T − t) + γσ²(T − t)/2 + (1/γ) ln(1 + γ/k) = ((1 + 2q)/2) γσ²(T − t) + (1/γ) ln(1 + γ/k)`,与 L02 脚注 8 转述的 AS 近似逐项相同。
- 记号提醒:任务书用同一对符号 δ^a、δ^b 表示"点差的两半之和",而原文的 δ^a、δ^b 是**到中间价 s 的距离**,不是到保留价 r 的距离。库存不为零时 `δ^b ≠ δ^a`,但 `P_a − r = r − P_b`。实现时不要把"到 r 的半点差"存进名为 δ 的变量。

### 2.4 任务书未写、原文有的内容

- 原文另有无限期版本(§2.3 p.219),用贴现率 ω 代替 T,给出的是冻结库存下的平稳保留价 `r̄^a`、`r̄^b`,并要求 `ω > (1/2)γ²σ²q²`。原文没有给出无限期下带挂单的最优报价闭式。本市场 24 小时交易、没有 T,若要用 AS 式,(T − t) 取什么值在原文里**没有依据**。
- 原文的数值实验参数(p.222):"s = 100, T = 1, σ = 2, dt = 0.005, q = 0, γ = 0.1, k = 1.5 and A = 140",是人为取值,不是估计值。

## 3. GLFT 逐项比对

| | 式子 |
|---|---|
| 任务书 δ^b | `(1/γ)·ln(1 + γ/κ) + ((2q + 1)/2)·sqrt( (σ²·γ)/(2·κ·A) · (1 + γ/κ)^(1 + κ/γ) )` |
| 原文 p.11 | `δ^{b*}_∞(q) ≃ (1/γ) ln(1 + γ/k) + ((2q + 1)/2) √( (σ²γ/(2kA)) (1 + γ/k)^{1 + k/γ} )` |
| 任务书 δ^a | `(1/γ)·ln(1 + γ/κ) − ((2q − 1)/2)·sqrt( (σ²·γ)/(2·κ·A) · (1 + γ/κ)^(1 + κ/γ) )` |
| 原文 p.11 | `δ^{a*}_∞(q) ≃ (1/γ) ln(1 + γ/k) − ((2q − 1)/2) √( (σ²γ/(2kA)) (1 + γ/k)^{1 + k/γ} )` |

逐项:

- 第一项、系数 (2q ± 1)/2、根号内的 σ²γ/(2kA)、指数 1 + k/γ、δ^a 前的负号:全部一致。κ ↔ k。
- 下标 ∞:原文写的是 T→∞ 的渐近值的近似。任务书省略了下标,等于省略了"远离终止时刻"这个条件。
- 这是哪一种近似(D3):
  1. 精确解(定理 1,p.7):`δ^{b*}(t, q) = (1/k) ln(v_q(t)/v_{q+1}(t)) + (1/γ) ln(1 + γ/k)`,其中 `v(t) = exp(−M(T − t)) × (1, …, 1)′`,M 是 (2Q+1) 阶三对角矩阵,对角元 αq²,次对角元 −η,`α = (k/2)γσ²`,`η = A(1 + γ/k)^{−(1 + k/γ)}`。
  2. 渐近极限(定理 2,p.10,精确):`δ^{b*}_∞(q) = (1/γ) ln(1 + γ/k) + (1/k) ln(f⁰_q / f⁰_{q+1})`,f⁰ 是 M 最小特征值对应的特征向量。这一步是谱分解的结果。
  3. 闭式近似(p.10–11):把 R^{2Q+1} 上的特征值问题换成 L²(R) 上的连续问题,命题 3 给出 `f̃⁰(x) ∝ exp(−(1/2)√(α/η) x²)`,于是 `(1/k) ln(f⁰_q / f⁰_{q+1}) ≃ (1/(2k)) √(α/η) (2q + 1)`。原文称 "This heuristic viewpoint"。任务书的式子是这第三步的结果。
- 近似质量:原文 p.11–12 "satisfactory in most cases and are always very good for small values of the inventory q … we cannot expect a very good fit for the quotes when q is large"。
- 库存上限(D4):模型要求 |q| ≤ Q,q = Q 时不挂买单,q = −Q 时不挂卖单(p.5)。闭式里没有 Q。实现时库存上限要另外加,它不是闭式的一部分。
- q 的含义(D5):p.4 "we assume that transactions are of constant size, scaled to 1";脚注 5 "The only important hypothesis is the constant size of orders since we can easily replace 1 by any positive size ∆";回测里 "the unit being the ATS"(p.20)。所以 q 是"净买入笔数",整数。
- 点差:原文同时给出 `ψ*_∞(q) ≃ (2/γ) ln(1 + γ/k) + √( (σ²γ/(2kA)) (1 + γ/k)^{1 + k/γ} )`,与任务书两式相加的结果一致(`δ^b + δ^a` 中 q 抵消,系数为 ((2q+1) − (2q−1))/2 = 1)。
- 参考价(D7):p.4 脚注 3 "This reference price for the stock can be thought of as a smoothed mid-price for instance."
- 参数估计:原文只有一句(§7 p.20)"σ, A and k can be calibrated on trade-by-trade limit order book data while γ has to be chosen",并补充 "A and k have to depend at least on the actual market bid-ask spread … in practice, the value of A and k are function of the market bid-ask spread"。没有给出估计步骤。估计步骤的唯一已核对来源是 L04(博士论文,丙类)。

## 4. 量纲

记 P = 价格单位(每 1 个资产单位的计价货币数),N = 资产数量单位,M = 货币单位 = P·N,t = 时间。

| 符号 | 需要的单位 | 说明 |
|---|---|---|
| δ^a、δ^b、r、S | P | 价格 |
| σ | P·t^{−1/2} | 算术布朗运动的波动率,是**价格差**的波动率,不是收益率的波动率。原文图注:"Tick·s^{−1/2}"(L02 p.11) |
| A | t^{−1} | 到达强度,单位是"笔/时间",不是"数量/时间"。原文图注:"s^{−1}" |
| κ (= k) | P^{−1} | 原文图注:"Tick^{−1}" |
| γ | M^{−1} | CARA 系数作用在财富 X_T + q_T S_T 上(L01 §2.2;L02 p.5) |
| q | N(AS、GLFT 中是以一笔为单位的整数) | |
| T − t | t | |

检查:

- `γ/κ` 的单位是 M^{−1}·P = N^{−1},**不是无量纲**。它之所以能放进 ln(1 + ·),是因为原文把单笔数量规定为 1,等于写的是 γ·1/κ。L02 图注里 γ 的单位写成 Tick^{−1}(而不是 (Tick·股)^{−1})正是这个约定的体现(D6)。
- `q·γ·σ²·(T − t)`:N·M^{−1}·P²·t^{−1}·t = N·P²/(P·N) = P。成立。
- AS 点差里的 `γσ²(T − t)`:M^{−1}·P² = P/N。同样隐含乘以"1 个单位"。
- GLFT 根号项:`σ²γ/(κA)` 的单位是 P²t^{−1}·M^{−1}·P·t = P³/M = P²/N;开方得 P·N^{−1/2}。只有 N 取"1 笔"为单位时才是 P。
- 任务书写的"γ 的单位是 1/money per unit inventory"不够准确:γ 的单位是 1/货币;"每单位库存"是由单笔数量 = 1 这个约定带进来的,应该显式写成 γΔ。

因此:**σ 必须用价格单位(美元/√秒)而不是 bp/√秒;κ 必须用 1/美元;若改用 bp 作价格单位,σ、κ、γ 要同时换算**。原文没有讨论相对价格(对数价)版本的闭式;L01 脚注(p.218)只说明可以用 `dS_u/S_u = σ dW_u` 配合均值–方差目标,细节在其附录,本次没有核对该附录。

## 5. 单笔为 Δ 个单位时式子怎么变(据 L03)

L03 设定(p.5):"assets are traded ∆ by ∆",`dq_t = ∆ dN^b_t − ∆ dN^a_t`,q 以资产数量计,取值为 Δ 的整数倍;强度 `Λ(δ) = A e^{−kδ}` 仍是**笔数**的强度。

L03 式(4.6)、(4.7)(p.21),ξ > 0:

```
δ^b_approx(q) = (1/(ξΔ))·log(1 + ξΔ/k) + ((2q + Δ)/2)·sqrt( γσ²/(2AΔk) · (1 + ξΔ/k)^(k/(ξΔ) + 1) )
δ^a_approx(q) = (1/(ξΔ))·log(1 + ξΔ/k) − ((2q − Δ)/2)·sqrt( γσ²/(2AΔk) · (1 + ξΔ/k)^(k/(ξΔ) + 1) )
```

ξ = 0:

```
δ^b_approx(q) = 1/k + ((2q + Δ)/2)·sqrt( γσ²e/(2AΔk) )
δ^a_approx(q) = 1/k − ((2q − Δ)/2)·sqrt( γσ²e/(2AΔk) )
```

- ξ 的含义(L03 p.6、p.8):Model A 是 CARA 期望效用 `E[−exp(−γ(X_T + q_T S_T − ℓ(|q_T|)))]`,对应 ξ = γ;Model B 是风险中性加持仓惩罚 `E[X_T + q_T S_T − ℓ(|q_T|) − (1/2)γσ² ∫_0^T q_t² dt]`,对应 ξ = 0。
- 原文确认(p.21):"we recover, in the specific case where ∆ = 1 and ξ = γ, the Guéant-Lehalle-Fernandez-Tapia's formula"。
- 原文说明(p.21):这些近似 "independent of t and of the final penalty function ℓ"。

与任务书 GLFT 式的换算(以下一步是本文档作者的代数推导,不是原文语句):令 q = nΔ(n 为净买入笔数),ξ = γ,则

```
((2q + Δ)/2)·sqrt( γσ²/(2AΔk) · X ) = ((2n + 1)/2)·sqrt( (γΔ)σ²/(2Ak) · X ),  X = (1 + γΔ/k)^(1 + k/(γΔ))
```

即:**把任务书 GLFT 式里的 γ 全部换成 γΔ,q 换成笔数 n**,就得到 L03 的 Model A 式。量纲上 γΔ 的单位是 P^{−1},γΔ/k 无量纲,第 4 节的问题消失。

实现含义:

- 若 Δ 以 BTC 计(例如 0.1 BTC),γ 以 1/USDT 计,则进入公式的是 γΔ(单位 1/美元价格)。改变单笔下单量而不改 γ,报价会变;这是模型的性质,不是错误。
- A 是"在距离 δ 处每单位时间被成交的**次数**"在 δ = 0 的外推值。把成交量(BTC/秒)当作 A 代入是错的。
- L03 的 Model B(ξ = 0)闭式没有 γ 出现在第一项,第一项是 1/k。任务书没有要求 Model B,此处仅记录。

## 6. A 与 κ 的取得方式:原文说了什么

- L01 §2.5(p.220)给的是一个推导:市价单频率 Λ、市价单大小的幂律指数 α、冲击 `Δp ∝ ln(Q)` 的系数 K,合成 `λ(δ) = A exp(−kδ)`,"where A = Λ/α and k = αK"。Λ 的估计:"dividing the total volume traded over a day by the average size of market orders on that day"。原文没有做估计。
- L02 §7(p.20)只说可以在逐笔数据上标定,并说 A、k 应随市场点差变化。
- L04(博士论文,丙类)第 4 章给出可执行的步骤:对每个距离 δ 估计窗口 ΔT 内的成交强度 Λ̂(δ)(按计数,§4.4.1;或按等待时间的截尾指数极大似然 `λ̂ = Σ1_{X_i<T} / ΣX_i`,§4.4.2),再最小化 `Σ_δ ( log Λ̂(δ) + kδ − log A − log ∫_0^{ΔT} ϕ(k, ξ) dξ )²`(Definition 1,印刷页 87)。其中 `ϕ(k, ξ) = E[e^{k(S_ξ − S_0)}]` 是参考价在窗口内移动带来的修正项。
- 与任务书描述("数一数距离 δ 处的报价会被打到多少次,再拟合指数")的差异:(a) L04 的回归式多一个依赖 k 和 σ 的修正项,直接对 log Λ̂(δ) 做直线回归会把这一项并进截距,只有当它对 k 的依赖可忽略时才等价;(b) L04 以 tick 为格点,用的是一档数据;(c) L04 假设别人的成交概率等于我方挂单的成交概率,没有排队;(d) L04 没有给出指数形状的拟合优度检验。
- 这一步的依据目前只有丙类来源。Cartea–Jaimungal–Penalva 教材等候选来源未取得(见台账第 4 节)。

## 7. 未能核对的事项
