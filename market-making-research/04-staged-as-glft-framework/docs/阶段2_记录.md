逐小时回归(训练 / 验证 / 10 月):
- log κ 对 log σ:斜率 −0.58 / −0.60 / −0.41(假设预言 −1),R² 0.54–0.67。
- log(不利变动)对 log σ:+0.15 / −0.41 / +0.07,R² ≤ 0.04。不利变动的均值 8.8 / 8.5 / [金额已抹] = 1.12 / 1.06 / 1.07 bp。
- log σ² 对 log 每秒吃单笔数:+1.30 / +1.20 / +1.23,R² 0.77–0.90;对每秒成交张数:+1.05 / +0.95 / +0.89。
- log A 对 log 每秒吃单笔数:−0.45 / −0.49 / −0.56(假设预言 +1)。

结论:
- 假设 (a)(价格类的量随波动缩放)**不成立**:1/κ 只部分随波动变(弹性约 0.6),成交后的不利变动基本是个常数(约 1.1 bp)。【预期】"小 tick 品种以波动率单位更合适"在这个品种上没有得到支持。
- 假设 (b) 对 σ 成立、对 A 不成立:σ 在事件时间下稳定得多;A 反而在日历时间下最稳定(A 的估计带"参考价移动"修正,活跃时修正变大、A 变小,这是估计方法的性质,见阶段 1 第 1 节)。
- 单位的选择:价格类 bp、时间日历秒,**不变**。研究六在单品种上没有可并入的改动。
- 带给后续研究的三条事实:κ 对 σ 的弹性 −0.6(研究二);逆向选择成本约 1.1 bp 且不随波动变(研究三);波动的变化大部分可由成交活跃度解释(研究一、七可用作状态变量)。
- 没有做的:无量纲组的跨品种比较与迁移损失(需要其它品种的同口径估计);库存单位(研究四);信号归一化(研究一有信号之后)。

追加检验(预登记 8b,`vol_event_time.py`):用成交活跃度预测波动。验证段 H = 60 秒:只用活跃度 QLIKE 4.002(对指数加权 DM +3.0,更差);每笔方差 × 活跃度 3.966(DM −0.5;10 月 −1.8),不显著。σ_t 的候选维持指数加权 600 秒。
