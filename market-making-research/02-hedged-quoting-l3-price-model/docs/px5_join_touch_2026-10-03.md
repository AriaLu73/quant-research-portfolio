# PX-5 加入最优价队尾 + 模型撤单,按真实排队 — 预登记,2026-10-03,先于任何 PX-5 结果

PX-4:9 月 480 小时、"永远在队首"口径下,带盾的贴盘口挂单 +0.33 bp / 笔、92% 小时为正(固定参数即可)。那是上界。
PX-3:10 月逐笔委托、真实排队、只测"新价位诞生时早到"的挂单 → 约 0。本检验回答中间缺的那一块:**一张普通的、排在最优价队尾的挂单,带同一面盾,按真实排队位置值多少。**
方法出处:Moallemi & Yuan 2017 §5.1 的人工订单回测(随机时刻插入队尾的 regular order;被后到的同价订单成交才算成交;同侧出现更优价即撤)。

## 1. 挂单
- BTC-USDT 逐笔委托(10-01、10-02)。每秒整点、买卖各一张无穷小虚拟单,加入当时最优价,排在该价位所有 orderTime ≤ 到达时刻的订单之后。
- 成交:排在我们后面的同价订单被吃,或该价位被打穿。结束:成交;同侧出现更优价(1.5 ms 后看到、τ 后撤单生效,期间成交仍算);10 秒到期(TTL)。
- 盾(与 PX-3 冻结规则完全相同,不再选任何参数):模型 ridge_v2 每 2 ms 预测 1 秒收益;到达前 5 ms 的预测不利(≤ −0.087 bp)则不挂;在场期间预测不利则撤(1.5 ms + τ 生效)。
- 净值 = 10 秒 markout + 我方费率。

## 2. 判定
- 主口径 τ = 25 ms,另报 5 ms。
- 通过线(10-01 与 10-02 **分别**满足):每笔净值 > 0 且按小时聚类 t ≥ 2;小时合计为正的比例 ≥ 60%;每小时成交 ≥ 50 笔。
- **声明**:这两天在 PX-2 / PX-3 用过(另一类挂单;10-02 按小时拆看过)。本检验没有可调参数,但仍只算"暂定";通过后须在工作日新数据上再确认,不通过照常判 NOT_PASSED。
- 同时报:不设盾的对照;成交时的排队位置(前面的量 / 整档量)分组;成交率;到成交的等待时间;撤单次数。

## 结果(2026-10-03;data/research3/px/px5/px5_eval_run.txt)

| | 10-01(11 小时,6.8 万张) | 10-02(21 小时,13.9 万张) |
|---|---|---|
| 不设盾:成交率 / 每笔净值 | 27% / −0.63 bp | 31% / −0.87 bp |
| 带盾 τ 25 ms:成交 / 小时 | 145 | 164 |
| 带盾 τ 25 ms:每笔净值(按小时 t) | −0.86(−1.9) | −0.59(−5.2) |
| 带盾 τ 25 ms:小时为正 | 0/11 | 1/21 |
| 带盾 τ 5 ms | −1.01 | −0.64 |
| 带盾 τ 0 ms(无延迟) | −1.09 | −0.64 |

**判定:NOT_PASSED(两天都不过)。** 排在队尾的挂单,带盾也是每笔 −0.6…−0.9 bp,而且与撤单快慢无关(零延迟也一样)。
按加入时前面排的量分组(τ 25):≤ 0.1 BTC +0.4…+0.6(样本只有 9–40 笔)、0.1–0.5 BTC −0.3…−0.4、> 0.5 BTC −0.7…−1.1 —— 前面排得越多越亏。

**三次测量拼起来(同一面盾、同一个模型)**
| 排队位置 | 每笔净值(含返佣) | 出处 |
|---|---|---|
| 永远在队首(假设,上界) | +0.33 bp,92% 小时为正 | PX-4,9 月 168 小时 |
| 新价位诞生后 5 ms 早到(靠前) | 撤单 ≤ 2 ms +0.57;5 ms +0.18;25 ms −0.03;为正小时 9/22 | PX-3,10-02 |
| 加入最优价队尾 | −0.6…−0.9,与撤单速度无关 | PX-5,10-01 / 10-02 |

结论:模型(方向预测 + 撤单)本身是有效的,但**能不能赚钱由排队位置决定**——与 Moallemi–Yuan、Albers 的结论一致(队尾只会被大单吃到,大单有信息)。
盾救不了队尾的单:队尾被成交时前面整条队列已经被吃光,那就是一次扫单。
未消除的混杂:PX-4 是 9 月、PX-3/5 是 10 月(10-01 后盘口变窄);要分开"月份"与"排队位置",需在 10 月数据上再做一次队首口径,或用新数据。
