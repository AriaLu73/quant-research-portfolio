## 2. PX-7:秒内时钟在 KuCoin 上成立吗?——不成立
脚本 scripts/research3/px7_subsecond.py;9 月 BTC-USDT 480 小时(训练 312 / 样本外 168),按 50 ms 分 20 箱。
- 吃单笔数与成交量在一秒内基本均匀(每箱 4.6–5.6%),没有整秒尖峰。
- 挂单方 10 秒净值(队首口径)各箱在 −0.24…+0.09 bp 之间乱跳,训练与样本外不一致(0–50 ms:−0.06 / −0.11,t −2.6 / −1.6;最差的箱样本外是 600–650 ms)。
- 结论:**不采用"按秒内时刻收放报价"**。(币安上的现象可能是真的,但传到 KuCoin 时不按 KuCoin 的整秒对齐。)
- 副产品:9 月这个口径(只算打在显示最优价上的吃单)按量加权是 −0.26 / −0.47 bp,比按笔数(0.00 / −0.08)更差——与 10 月逐笔委托上"按量加权为正"相反。"大吃单是良性的"还不能当成定论(口径不同:9 月不含非最优价成交;月份不同),见第 4 节。

## 3. PX-8:围绕领先场所(币安)的价格报价——成立,但对信息新鲜度很敏感
脚本 scripts/research3/px8_leader.py;币安 BTCUSDT 永续逐笔成交(data/research5/binance_hist,10-01 / 10-02)对 KuCoin BTC-USDT 逐笔委托。
公允价 = 币安最新成交价 × exp(过去 60 秒的平均基差);gap = ln(KuCoin 中价 / 公允价)。

**A. 作为价格预测信号(IC)**
| 信息延迟 | 1 s 秩 IC(10-01 / 10-02) | 10 s 秩 IC |
|---|---|---|
| 0–5 ms | 0.18–0.19 / 0.20 | 0.14 / 0.15 |
| 25 ms | 0.17 / 0.19 | 0.13 / 0.15 |
| 200 ms | 0.12 / 0.13 | 0.11 / 0.12 |
全部小时为正(11/11、22/22)。但**对盘口模型没有增量**:10-02 上盘口模型 1 s IC 0.365,加上 gap(权重在 10-01 上拟合)0.356;10 s 0.243 → 0.240。即 KuCoin 的盘口失衡已经反映了币安的变动,gap 不提高对中价的预测。

**B. 作为报价位置的判据(这才是用处)**
对每笔真实挂单成交算 q = 方向 × (公允价 − 成交价),bp:挂单被吃时,它相对币安公允价站在对的一侧多少。净值 = 10 秒 markout + 我方费率。

| 信息延迟 | q 与成交净值的秩 IC(10-01 / 10-02) | q 最低十分位 → 最高十分位(每笔净值) |
|---|---|---|
| 2 ms | 0.198 / 0.150 | −1.37 → +0.80 / −1.56 → +0.60 |
| 6.5 ms(我们的行情 1.5 + 撤单 5) | 0.115 / 0.085 | −0.75 → +0.37 / −1.11 → +0.52 |
| 26.5 ms | 0.074 / 0.061 | −0.57 → +0.18 / −0.94 → +0.39 |

规则"只有 q ≥ θ 才留在簿里"(每笔成交按 0.06 BTC 封顶、按量):
| θ | 2 ms:10-01 / 10-02(为正小时) | 6.5 ms | 26.5 ms |
|---|---|---|---|
| 不筛 | −0.08 / −0.22(5/11、11/22) | 同左 | 同左 |
| ≥ 0 | +0.42 / +0.28(9/11、18/22) | +0.14 / −0.01(7/11、16/22) | +0.04 / −0.08 |
| ≥ 0.25 bp | +0.65 / +0.35(8/11、19/22) | +0.29 / +0.07(8/11、18/22) | +0.15 / −0.05 |
| ≥ 1 bp | +1.17 / +0.80(7/11、16/22) | +0.61 / +0.42(6/11、14/22) | +0.36 / +0.18 |

读法:
1. 挂单价相对币安公允价的位置,决定了这笔成交是赚是亏——单调、两天一致。这就是论文说的"本所价格的偏离是噪声":我们的买单比公允价低(q > 0)时被吃,对方吃的是噪声;高于公允价时被吃,对方是在搬币安的价。
2. 它不改善"预测中价"(A),但改善"在哪个价位挂"(B):盘口模型回答"要不要撤",公允价回答"挂在哪"。两者互补。
3. 对延迟极敏感:信息 2 ms 新 → 6.5 ms → 26.5 ms,q ≥ 0 的净值 +0.3…+0.4 → 约 +0.1 → 约 0。门槛提高(q ≥ 1 bp)可以换回一部分,成交数降到每小时 200–400 笔(全市场真实成交口径)。
4. 按小时的 t 都不高(0.2–1.8),因为小时合计的尾部很重;为正小时占比是主要证据。
局限:这是在真实做市商已经成交的单里按 q 事后筛选(他们有自己的撤单);两天数据此前用过;θ 没有预登记。只能算"方向明确的描述性证据"。

## 4. 改后的报价方式(待按策略回放检验,未检验)
1. **定价锚**:公允价 F = 币安价 × 基差(60 秒均值,归一化:门槛以 gap 的滚动标准差为单位)。不再以 KuCoin 自己的中间价为锚。
2. **挂在哪(10-03 用户更正后改写)**:**不贴盘口**,任何时候都挂在盘口外;以 F 为中心、离 F 至少 m 的阶梯(见第 5 节)。原稿写的"有利时贴盘口"是错的,与此前结论和下面的数据都矛盾。
3. **什么时候撤**:(a) F 移动使在挂的单 q < m;(b) 盘口模型预测不利(PX-3 的盾);(c) 本价位其他人撤光;(d) TTL。
4. **单量与评估**:有单量的挂单(0.06 BTC)、每侧一张、按量结算、按真实排队位置回放;对照真实挂单成交基准。
5. 不采用:秒内时钟(PX-7)。
6. 要先补的测量:信息延迟。我们到币安行情 p50 1.4 ms、撤单 p50 3.9 ms(急动时更慢),落在 6.5 ms 这一档附近;m 要按这档的结果定,不能按 2 ms 的。
