## 0. 设计依据(只来自开发日 10-01 的诊断,scratchpad/px_surv.py)
规则留下的成交里:挂上不到 20 ms 就成交的占 15%,每笔 −4…−7 bp(来不及撤,只能事前不挂);挂 1 秒以上才成交的 +4…+7 bp;
约四成成交与"本价位开始有成交"发生在同一毫秒(一口气扫过来,盘口内无预兆)。→ 模型要看更短的窗口、更新更勤,且"挂不挂"的判断要用诞生那一刻的状态。
(10-01 留存成交只有约 500 笔,这些数字噪声大,只用于定方向。)

## 1. 模型 v2(冻结后才看 10 月数据)
- 特征 = PX-1 的 17 个 + 短窗口 7 个,全部按时间定义、按过去 5 分钟归一化:
  ofi1_20ms、ofi1_50ms(Cont–Kukanov–Stoikov 2014 的 OFI,短窗口);tflow_50ms、tflow_200ms(主动成交净量);ret_50ms、ret_200ms(短期收益 / 波动);tint_100ms(成交强度)。
- 目标:200 ms、1 s、5 s 中价收益。岭回归,λ 按训练期留一天交叉验证。
- 训练数据:9 月清洗 L2(data/oos/ku_buyc)BTC-USDT,**10 ms 网格**,训练日 08-26…09-07 每天取 02、08、14、20 四个小时(事先固定,共 52 小时);样本外 09-10…09-24 同样四个小时(28 小时)只用于报告 IC。
- 按用户 IC 规则报告:秩 IC 均值、ICIR、t、为正小时比例,训练 / 样本外,v1 特征与 v2 新特征分别的增量。

## 2. 撤单 / 不挂规则(与 PX-2 相同的结构)
- 被测挂单:QMM 虚拟挂单(新价位诞生后 5 ms 到达,真实排队;data/research3/qmm/trace_<日>_d5*)。
- 预测:v2 模型在逐笔委托重建盘口上**每 2 ms** 算一次(px_l3grid.py,步长 2 ms)。
- 不挂:诞生时刻看到的最新预测(格点 ≤ 诞生时刻 − 1.5 ms)对该方向不利(≤ −θ)→ 不挂。
- 撤:此后任何格点预测 ≤ −θ → 1.5 ms 后看到,τ 后生效(τ = 5 / 25 ms)。TTL = k·h。
- 参数网格:h ∈ {200 ms, 1 s};θ = 开发日 |p_h| 的 q 分位,q ∈ {0, 0.5, 0.75, 0.9};k ∈ {2, ∞}。共 16 组。
- 开发日 10-01、τ = 25 ms 下选"每小时净 bp × 成交数"最高且 ≥ 50 笔/小时的一组,冻结。

## 3. 判定
- 检验日 10-02,τ = 25 ms:每笔净值(10 s markout + 0.7)> 0 且 t ≥ 2;≥ 50 笔/小时;≥ 60% 小时为正。三条同时满足 = 通过。

- 同时报:与 PX-2 冻结规则在同一天的对比、撤单次数 / 小时、反应时间敏感度(τ 0–50 ms)。

## 结果(2026-10-03;data/research3/px/px3_fit_run.txt、px3_cancel_run.txt、BTC-USDT/ridge_v2.json)

**模型 v2**:短窗口特征几乎不加 IC——样本外 1 s 秩 IC v1 特征 0.3334 → v2 0.3339,200 ms 0.2871 → 0.2879,5 s 0.2998 → 0.3000(28 小时全为正)。搬到 10 月逐笔委托盘口上:1 s IC 10-01 0.35、10-02 0.37。
**开发日选中**:h = 1 s,θ = |p| 的中位数(0.087 bp),不设 TTL。
**检验日 10-02(22 小时)**:

| 撤单生效 τ | 成交/小时 | 每笔净值(se) | 为正的小时 |
|---|---|---|---|
| 不撤单 | 1,324 | −0.83(0.04) | 1/22 |
| 0 ms | 103 | +0.57(0.19) | 10/22 |
| 2 ms | 109 | +0.57(0.19) | 9/22 |
| 5 ms | 118 | +0.18(0.18) | 9/22 |
| 10 ms | 132 | +0.06(0.17) | 9/22 |
| **25 ms(判定)** | 160 | **−0.03(0.15)** | 8/22 |
| 50 ms | 186 | −0.07(0.14) | 9/22 |
| 实测撤单延迟分布(p50 3.9 / p90 18.9 ms,5 次抽样) | 122 | +0.26…+0.36(0.18) | 9/22 |

**判定:NOT_PASSED**(净值不显著为正;为正的小时 8/22 < 60%)。

**为什么均值为正也不算数(τ = 5 ms 的逐小时拆解)**
- 留下的成交集中在少数急动小时:12 点 650 笔合计 +1,388 bp,04 点 560 笔 −628,17 点 228 笔 −454,14 点 310 笔 +269;其余多数小时只有 7–50 笔。全天合计约 +460 bp,去掉 12 点这一小时就是负的。
- 每笔净值的分布:1% / 10% / 50% / 90% / 99% 分位 = −25.8 / −9.6 / −0.16 / +11.1 / +32.7 bp,为正的只有 49%;去掉最好和最差的 1% 后均值 +0.12。
- 即:平静时模型几乎把所有会成交的单都提前撤掉了(预测一转向就撤,而成交恰恰发生在转向时——Albers 的"做市商两难");剩下的成交都发生在急动里,盈亏是 ±10 bp 量级的方向运气,不是稳定的 edge。"为正小时 ≥ 60%"这条线正是为挡住这种情况设的。

**学到的**
1. 更新频率比新特征重要:10 ms → 2 ms 把零延迟下的结果从 −0.05 提到 +0.57;短窗口特征本身没用。
2. 撤单延迟每慢几毫秒就掉一截:2 ms +0.57,5 ms +0.18,25 ms −0.03。
3. 用模型撤单是一面"盾":能把这类挂单从每笔 −0.83 做到约 0,但挡掉了九成成交,留下的不是利润。
4. 10-01、10-02 已反复用过(10-02 还按小时拆过),不能再当检验日。
