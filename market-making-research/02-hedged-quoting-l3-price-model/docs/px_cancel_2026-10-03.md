# PX-2 用价格模型撤单(第二道门)— 预登记,2026-10-03,先于任何结果

用户 10-03:"预测之后不是要往那边挂单,而是预测之后发现要走了然后马上撤单。"
PX-1(px_price_model_2026-10-03.md)的模型方向预测稳定(样本外秩 IC BTC 1 s 0.33),但平均幅度 < 1 bp,按第一道门停住;
用户明确把模型的用途定为**撤单**,第一道门(平均幅度)不是这个用途的判据,所以另立本检验。决定性的量是"在我们真被成交的那一刻,模型能不能提前把单撤走"。

## 1. 被测的挂单
QMM-2 的虚拟挂单(scripts/research3/qmm_trace.py,data/research3/qmm/trace_<日>_d5*.jsonl.gz):BTC-USDT 每个新盘口价位一张无穷小单,
价位诞生后 5 ms 到达、排在当时已有的单后面,最多留 5 秒;成交 = 排在后面的同价单被吃或价位被打穿;10 秒 markout + 我方费率 返佣。
不撤单时:开发日 10-01 −0.51 bp / 成交,检验日 10-02 −0.83 bp。成交时刻与是否成交已在轨迹里,本检验只决定"撤单时刻"。

## 2. 价格模型(冻结,不重新拟合)
PX-1 在 9 月训练期上拟合的岭回归(data/research3/px/BTC-USDT/ridge.json),特征定义不变(窗口按时间:100 ms / 1 s / 5 s / 30 s,归一化按过去 5 分钟)。
输入改为逐笔委托重建的盘口(scripts/research3/px_l3grid.py),每 10 ms 一个格点算一次预测 p_h。
已知差异:训练用 L2 增量(BTC 计),这里用逐笔委托重建(张 × 0.001 BTC);特征都是比值或已归一化,单位不影响。先报告 10-01 上模型的 IC,确认搬过来后预测力还在。

## 3. 撤单规则
- 方向:买单在 p_h ≤ −θ 时撤,卖单在 p_h ≥ +θ 时撤("要往不利方向走了")。
- 到达前(价位诞生时刻)预测已经不利 → 不挂。
- 反应时间:格点 g 的预测在 g + 1.5 ms 被我们看到(实测行情到机 p50 1.4 ms),撤单在此后 τ 生效,τ = 5 ms(中位)/ 25 ms(慢端)。10 ms 格点本身再带来 0–10 ms 的滞后(偏保守)。
- TTL(用户 10-03):挂单在 k·h 后到期撤单(同样 τ 后生效),k ∈ {0.5, 1, 2, ∞}。
- 成交判定:轨迹中的成交时刻早于撤单生效时刻才算成交。

## 4. 选参与判定
- 参数网格(全部事先列出):h ∈ {1 s, 5 s};θ = 开发日 |p_h| 分布的 q 分位,q ∈ {0(任何不利符号), 0.5, 0.75, 0.9};k ∈ {0.5, 1, 2, ∞}。共 32 组。
- 开发日 10-01(11 小时)在 τ = 25 ms 下选"每小时净 bp × 成交数"最高、且 ≥ 50 笔/小时的一组;冻结后检验日 10-02(22 小时)只读一次。
- **通过线(检验日,τ = 25 ms,三条同时满足)**:每笔净值(10 s markout + 0.7)均值 > 0 且 t ≥ 2;≥ 50 笔/小时;≥ 60% 的小时合计为正。
- 同时报:撤单次数 / 小时(限频)、被撤单里"本来会成交"的比例、按撤单原因(预测 / TTL)分的成交净值。

## 5. 局限
- 无穷小单、只覆盖"新价位早到"这一类挂单;真实单量与其它挂法另测。
- 只有 BTC-USDT 有逐笔委托数据;ETH 不能做这一步。
- 10 ms 格点不是逐事件,反应时间偏慢;若结果接近门槛,再改成逐事件计算。

## 结果(2026-10-03;输出 data/research3/px/px_cancel_run.txt、data/research3/px/cancel/)

- 模型搬到逐笔委托网格后预测力还在:冻结模型 1 s 秩 IC 10-01 0.35(11/11 小时为正)、10-02 0.37(22/22)。
- 开发日选中:h = 1 s,θ = 0(只要预测朝不利方向就撤),不设 TTL(k = ∞)。开发日 τ 25 ms:+0.13 bp,60 笔/小时。
- **检验日 10-02,τ = 25 ms:每笔 −0.30 bp(se 0.17,t −1.75),141 笔/小时,10/22 小时为正 → NOT_PASSED。** τ = 5 ms:−0.10 bp(se 0.19)。
  对照不撤单:−0.83 bp、1,324 笔/小时。规则把 29,136 笔成交里的约 17,500 笔撤掉了("本来会成交"),每笔亏损从 −0.83 缩到 −0.30。撤单约 3,100 次/小时。
- 诊断(不改变结论):反应时间对结果的影响——看到预测 1.5 ms、撤单 0 / 5 / 25 / 50 ms 生效:−0.08 / −0.10 / −0.30 / −0.44 bp;完全无延迟(看到 0 ms、撤单 0 ms)也只有 −0.05 bp(se 0.21)。
  即在 10 ms 一次的预测频率下,光靠更快也到不了正;剩下的亏损主要是在预测更新之前就发生的成交。
- 10-01、10-02 两天已用完;下一轮(逐事件更新预测、按逐笔委托重新训练)需要新的未见数据。
