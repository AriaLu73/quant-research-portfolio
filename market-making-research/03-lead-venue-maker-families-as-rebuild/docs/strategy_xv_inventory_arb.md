## 1 资料
- 主文献(通读):Hautsch、Scheuch、Voigt,Review of Finance 28(4) 2024(笔记:docs/research5/reading_notes_2026-10-01.md 末尾)。本策略直接用到的原文内容:
  - 两种套利(p.1350–1352):搬砖(买 → 链上转 → 卖,承担到账时间内的价格风险)与库存套利(两所预存资金,同时买卖,承担交易所违约风险)。
  - 入场条件(引理 3,式 16):扣交易成本后的价差 > 套利下界。
  - 套利下界(引理 2,式 12;估计式 29–31):δ = ½·σ·√( γ·m₁ + √( γ²·m₁² + 2γ(γ+1)(γ+2)·m₂ ) ),m₁ = E[τ],m₂ = V[τ] + E[τ]²;τ = 仓位平掉之前的随机等待时间,σ = 等待期间的价格波动。
  - 等待时间的预测(5.2 节,式 26–28):Gamma 久期模型,率参数 β = exp(−x′θ),E[τ] = α·exp(x′θ),V[τ] = α·exp(2x′θ);用前一天的数据估参数、预测当天(不看未来)。
  - γ = 2(p.1367;作者同时说明下界的水平取决于 γ,可解读的是各成分的相对贡献)。
  - 波动率:单侧核估计(Kristensen 2010),带宽用前一天的数据选(5.1 节)。
  - 实证方向(表 5):价差在 波动高、等待时间长且不确定 的时段更大。
- 衍生文献(15 篇,全文笔记与出处页码在 docs/research5/lit_cross_exchange_arbitrage.md;下面每条后面是该文件里的编号。Albers 等的数字我对照原文核对过):
  - 已被套平的:带转币的现货跨所套利 2018 年 4 月后净收益为负;USDT 交易所之间小时级最大价差指数 2019–2021 年年均 1.002–1.003(A2)。离岸所之间期货基差的交易所特有部分约 1%(B2)。
  - "领先所动了就去吃滞后所"在 2021 年已扣不掉手续费:我方费率 个 BTC 市场两两组合,普通吃单费下全部为负,最低费率档平均仍为负;作者的解释是滞后幅度被费率结构封顶(B5 第 4.2 节)。
    同一篇的实盘:在滞后所(Bybit)挂单、用领先所信号撤单,一个来回价格上亏 4.47 bp,靠 我方费率 返佣才净 我方费率(B5 第 6.3 节)。KuCoin 的来回返佣只有 我方费率。
  - 币安 USDT 永续是价格与波动的源头,高返佣、散户多的场所滞后(B5、B6)。
  - 价差按成因分两类:领先所先动造成的(速度赛,价格不回来)与本所流动性冲击造成的(会回归);只有后一类适合库存套利(C1 Foucault–Kozhan–Tham;A1 Makarov–Schoar 式 8)。
  - 入场门槛 = 来回成本;门槛越高,持有越久、尾部越厚:币安永续对现货,零成本时中位 2 小时,16.4 bp 成本档 BTC 中位 38 小时(B1 式 19、表 D.2)。
  - 两所永续之间存在非零的均衡基差是理论预期(资金费参数、上下限不同),只应交易相对慢基差的偏离(B3、B1)。
  - 两条腿分属两个保证金账户时,方向对冲也会被单腿强平(B2 图 5;C2 式 16–17:一价定律成立需要 W ≥ 2|u|ε)。跨所调保证金是今天意义上的"到账时间";交易所自己的处理时间按小时计、行情极端时最长(A4)。
  - 文献空白:没有论文在高频上度量同一永续在两家中心化所之间的价差(除 B5 的 BTC),也没有覆盖 KuCoin 对币安的腰部币永续。
  - 对设计的影响:① τ 应是"两条腿之间的延迟",不是回归时间(A-2 的教训,A-3 改正);② 全吃单的机会只在成本更低的对手额度用尽时出现,量小;③ 论文意义上的风险下界应当用在"跨所调保证金"这一步,而不是每笔交易上。
- 我方已有的相关结果:A-1(同一批数据):挂吃不成立;吃吃在固定门槛 15–30 bp 时入场净为正,但 300 秒平仓后的落袋值不稳,约 [金额已抹]/天;L-3/L-4(TradFi):币安领先 KuCoin,成交价参考有噪声。

## 2 假设
- H1(论文预测在我方数据上的复现):KuCoin 与币安同名永续之间可成交的价差(相对慢基差),在波动高的小时更大。——描述性检验,决定"下界随波动缩放"是否有依据。
- H2(策略):只在 可成交价差 − 来回四条腿的成本 ≥ 套利下界 δ(σ, E[τ], V[τ]) 时入场、在价差回到慢基差时平仓,每美元的落袋收益为正;
  并且比固定门槛(A-1 的 S1)更稳:下界在"波动大、回归慢"时自动抬高门槛。
- H3(容量):单笔受 KuCoin 最优价挂量限制(A-1:每笔 [金额已抹]),量级由机会次数决定。
- 论文里的 τ 是链上到账时间;永续合约没有币要转,这里把 τ 改成"价差回到慢基差所需的时间"(仓位能无损平掉之前要等多久),σ 改成价差本身的波动。这是把论文的框架搬到我们的场景,属于【推导】,不是论文的结论。

## 3 数学定义(scripts/research5/xv_inventory_arb.py;每个函数有单测)
- 币安盘口:用成交价合成(同 A-1):中价 = 最近成交价 ∓ hs;可吃价 = 中价 ± hs;下单成交价取"到达时刻前最后一笔"与"之后 1 秒内第一笔"中对我方更差的。
- 慢基差 b:ln(KuCoin 中价 / 币安中价) 过去 600 秒的滚动中位数(每秒一点,不含当前秒)。
- 价差(中价口径)x_t = ln(KuCoin 中价 / 币安中价) − b,单位 bp;可成交价差 d = KuCoin 最优买价相对币安可买价(或反向)的有利差。
- 价差波动 σ_x:√(π/2)·E|Δx| 每 √秒,单侧指数加权、时间常数 600 秒(论文用单侧高斯核;我们用同样是单侧的指数核,与策略里其它估计量一致——偏离论文之处,已标明)。
- 等待时间 τ:从某一秒起,到 x 第一次回到 0(按入场方向计)所经过的秒数;超过 1800 秒按 1800 秒截尾。
- Gamma 久期模型:协变量 = [1, ln|x|, ln σ_x];log 链接;只用训练日拟合,预测检验日。
- 套利下界:δ = ½·σ_x·√(γm₁ + √(γ²m₁² + 2γ(γ+1)(γ+2)m₂)),γ = 2(论文取值,不调)。
- 入场:看到币安成交后 1.5 ms 决策;若 d ≥ C_入 + C_出 + δ 则以所见 KuCoin 最优价发 IOC(3.0 ms 后该价位还在才成交,量 = min([金额已抹], 该档挂量)),成交后 1.8 ms 在币安反向吃单。
  C_入 = 1.8 + 5.0;C_出 = 1.8 + 5.0 + 当前 KuCoin 半点差 + 币安 hs(出场也要吃单过点差)。
- 出场:入场 1 秒后,x 按入场方向回到 ≤ 0 的第一秒,两腿吃单平仓;1800 秒仍未回归则按当时可成交价强制平仓。
- 库存:每个合约每个方向最多同时持有 3 笔;同侧 100 ms 内只出手一次。
- 落袋收益(每美元,bp)= 两腿各自的(入场价 − 出场价)按方向合计 − 13.6。

## 11 失败分析
1. **转置错了(A-2)。**我把论文的 τ(两条腿之间必须等的时间)换成了"价差回归时间",又把每秒波动按 √τ 放大。价差是会回归的量,不是布朗运动,这样算把风险高估了一个数量级,门槛高到没有交易。
   按论文原意,库存套利两腿之间只隔 1.8 ms,下界不到 0.3 bp——**在我们的场景里,论文的"风险下界"几乎为零,限制套利的只剩费用。**
2. **入场时看到的价差,一半在对冲成交前就没了。**不含 AKE 仍丢 12–13 bp(即使要求币安上一笔成交确认了我方要吃的那一侧)。
   对冲价是保守口径;按乐观口径同一规则约 +6 bp。真实值在两者之间,成交价合成的币安盘口定不了。
3. **量太小。**超过全部成本的时刻每天只有 [金额已抹]可成交(21 个合约合计,每笔 [金额已抹],受 KuCoin 最优价挂量限制)。即使符号为正也只有每天几十美元。
4. **宽点差合约(AKE)上,出场不看点差的固定门槛规则每笔亏一个点差**(A-2 检验日"平仓付出"33 bp)。主规则把当前点差放进门槛后这一项消失,但也不再有利润。
5. 与文献一致:吃单方的门槛由费率最低的对手决定(B5);我们四条吃单腿 13.6 bp,价差在走到这里之前先被别人套平。
